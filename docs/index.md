# zensical

Terrain d'expérimentation de scripts JS et de personnalisations pour Zensical.

## Fonctionnalités

- [Toggle sidebar](toggle-sidebar.md): bouton et raccourcis clavier pour masquer/afficher nav et table des matières.
- [On this page](on-this-page.md): clic sur le titre de la ToC pour remonter en haut de page.
- [CodeBlock](codeblock.md): blocs de code enrichis (transcript repliable, flou, peek, icônes de fichier).
- [open-in-new-tab](open-in-new-tab.md): liens externes et fichiers téléchargeables ouverts dans un nouvel onglet.
- [Placeholders](variables.md): valeurs éditables par le lecteur, synchronisées en direct sur la page.

Chaque feature a son propre dossier à la racine du dépôt ([`toggle-sidebar/`](https://github.com/Mathod95/zensical/tree/main/toggle-sidebar), [`on-this-page/`](https://github.com/Mathod95/zensical/tree/main/on-this-page), [`codeBlock/`](https://github.com/Mathod95/zensical/tree/main/codeBlock), [`open-in-new-tab/`](https://github.com/Mathod95/zensical/tree/main/open-in-new-tab), [`placeholders/`](https://github.com/Mathod95/zensical/tree/main/placeholders)) avec un `README.md` et un `example/` prêt à copier sur un autre projet Zensical.
